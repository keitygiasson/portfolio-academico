## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie **todos os arquivos desta pasta** para a raiz do repositório.
3. Em Settings → Pages → Build and deployment, selecione Deploy from a branch, `main` e `/ (root)`.
4. Aguarde a publicação e copie o link indicado pelo GitHub.

## Observações
O dashboard usa Chart.js via CDN e necessita de internet para renderizar os gráficos. O chat é um assistente demonstrativo de consultas guiadas, **não** um LLM conectado. Para atender literalmente ao requisito de agente de IA conversacional, integrar um backend seguro com API de LLM e documentação de fontes; não coloque chaves no navegador. O link do site só existe após a publicação na sua conta. A previsão é regressão linear exploratória, não validada.
